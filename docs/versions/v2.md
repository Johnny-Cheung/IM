## 共同原则

- **不为新功能套用聊天的可靠投递管道。** 朋友圈是低写入频率、强关系型、需要事务和分页的数据，直接用 MySQL；Redis 只在确有读性能需要时再引入。
- **权限先于数据。** 可见性、点赞、评论、删除都在服务端校验，不依赖前端隐藏。
- **复用现有身份和关系。** 用户、好友、会话登录和 WebSocket hub 直接复用；不新建账号体系，不复制好友关系。
- **先小后大。** v2.0 只做文字，图片、隐私名单和通知等确认后再加，避免一次改动过大。
- **不改变 v1.x 行为。** 聊天消息、未读、已读、对账和重建逻辑保持不变。

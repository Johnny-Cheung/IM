# v1.1 性能基线与基础设施准备

状态：范围已确认，细节待讨论，尚未开始实现。

## 目标

在不改变现有业务逻辑的前提下，建立 v0.7 的性能基线，准备 Redis 和 RabbitMQ 的运行与接入基础，为后续私聊和群聊链路优化提供可验证的基础设施。

## 已确认范围

- 以当前 v0.7 运行和回归行为作为性能基线。
- 对私聊发送、私聊已读、群聊发送、群聊未读/已读相关请求、会话列表和历史消息读取建立可重复的基础测量。
- 在开发机上准备独立的 Redis 和 RabbitMQ 运行配置、数据目录、资源限制和启停方式。
- 后端具备 Redis 和 RabbitMQ 的基础连接能力、健康检查、超时处理、断开处理和基础重连能力。
- 完成 Redis 基础读写验证，以及 RabbitMQ 基础发布、消费和确认验证。
- 验证 Redis 或 RabbitMQ 重启后，后端能够发现连接异常并恢复连接。
- 增加基础运行状态观察，能够了解连接状态、队列积压、消费失败和重连情况。
- v0.7 的 API、浏览器和容量边界回归继续通过，确保准备基础设施没有影响现有业务。

## 本版边界

- 不把私聊消息切换到 Redis 邮箱。
- 不把群聊消息切换到群统一邮箱。
- 不把私聊已读或群聊未读/已读切换到 Redis。
- 不引入消息邮箱、游标拉取或新的消息广播业务模型。
- 不改变当前“消息保存成功后视为已发送”的行为。
- 不修改私聊、群聊和已读接口的用户可见语义。
- 不新增业务数据库表，不修改现有消息、群聊和已读数据结构。
- 不做多实例、高可用、自动故障切换或公网部署。
- 不做完整压力测试和大规模容量调优；容量验证和调优属于后续 v1.5。
- 不修改前端页面和用户操作流程。

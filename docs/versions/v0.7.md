# v0.7 整体联调与部署

状态：已验收（2026-10-24）。

## 目标

完成账号、好友、私聊和群聊的整体回归，修复会话切换与断线恢复的边界问题，整理可重复的构建、发布、备份和回退流程，供少量用户持续试用。

## 已确认范围

- 沿用 Mac 开发构建、开发机运行；正式地址仍为 `http://10.12.75.191:8198/`。
- 验证实例使用 `8199` 和独立的 `im_v07_verify` 数据库；复用现有私有 MySQL 容器，不新增运行时基础设施。
- 保留现有账号、好友、历史消息和 `demo_*` 演示数据；写入测试使用独立生成的账号，清理只针对明确创建的记录或独立测试库。
- 固化 API 和浏览器回归入口，覆盖既有功能，并保留已知状态问题的复现与修复证据。
- 修复离线期间群变化在重连后未同步、延迟发送响应影响新会话的问题；把当前窗口的 WebSocket 连接提示表达清楚。
- 补齐管理脚本的依赖启动、严格健康检查、一致性备份和临时库恢复核验。
- 补齐当前 MySQL 前提、发布包校验、短暂后端切换、应用回退和手动恢复说明。
- 本版不新增业务权限或数据库结构，不做公网开放、开机自启、压测或高可用改造；不调整旧 `/opt/IM` 及宿主机既有服务。

## 关键验收场景

1. 注册登录、单账号登录替换、好友接受/拒绝记录、删除好友后的私聊只读回归通过。
2. 私聊与群聊的保存确认、重试去重、历史分页、断线补收和未读保持一致；私聊保留最后一条自己的已读提示，群聊无逐条回执。
3. 在旧会话发送后切换到新会话，旧请求延迟失败不能让新会话出现错误、非好友提示或禁用输入。
4. 成员离线期间群被改名，重连后群头部及已打开的信息面板恢复新名称和成员状态。
5. 成员离线期间被踢或群被解散，重连后清除旧群详情、返回列表并提示；只在服务器确认 `group_not_found` 时判定访问失效，普通网络错误可重试。
6. 前台、后台、刷新、群信息面板及单聊天连接接管在桌面和手机浏览器中正常，无横向溢出。
7. 群成员上限 100 的边界使用隔离夹具验证，不进行负载测试。
8. 管理脚本的依赖启动、就绪失败退出码和短暂后端重启可重复执行；备份可校验并恢复到独立临时库。
9. 发布包对应一个已提交版本，二进制、静态资源与 RELEASE 的哈希相符，应用回退经过验证。
10. 正式部署后健康和数据库就绪检查通过，现有数据和宿主机基线保持，验证实例停止。

### 2026-10-24 已读请求在途边界

- 最终候选回归中发现：前台已读请求尚未到达服务器时切到后台，新到消息可能被旧请求一起读掉；通过拦截该已读请求、切后台并插入新消息，稳定复现。
- 私聊和群聊的已读接口增加可选 `through_id` 查询参数。浏览器提交实际已看到的最大消息 ID，服务端只推进至该位置以内的当前会话消息；没有参数时保持旧接口行为，格式错误返回 400。
- 已读响应及私聊自己的已读事件不再直接把未读数置零，而是刷新服务器会话统计，保留请求在途期间新到的未读；已读位置保持单调递增。
- 无数据库结构变更。Go 单测/vet、前端类型检查/构建通过；真实 MySQL API 回归扩展为 56 项，浏览器扩展为 30 项，均通过，包含私聊与群聊的确定性在途已读场景。

### 2026-10-24 验收修正：切换会话保持左栏稳定

- 用户反馈切换聊天对象时，左侧列表重新加载并产生画面抽动。
- 原因是 BrowserRouter 中 `useNavigate` 的函数引用随路径变化，连带改变初始化和 WebSocket 回调依赖，重复加载列表、关闭并重建连接。
- 保留最新导航函数的 ref，并提供稳定的工作区导航回调；路由变化只触发当前对话消息及群详情的加载，列表初始化和实时连接不再跟随变化。真实新消息和已读状态仍按原有规则更新。
- 浏览器基线在无新消息的空会话间连续切换 5 次，测得 5 次列表加载态、7 次列表请求、5 个新 WebSocket，滚动位置由 90 变为 0。修复后列表和行节点保留，加载态/额外列表请求/新 WebSocket 均为 0，滚动位置保持 90，选中项正常更新。需要已读同步时仍静默刷新服务器统计，不重新显示列表加载态。
- 前端类型检查及构建通过；从干净提交 `528347e492533d1eb08a1aac483bef45a58d9485` 构建并部署到正式 `8198`。隔离环境和正式环境扩展后的 37 项浏览器检查均通过，包含未读、在途已读、断线群变化、会话接管与手机布局。
- 更新前备份 `/opt/IM-Rebuild/backups/20261024T074946Z-o4glRi`；更新后静态资源及二进制哈希匹配，健康与就绪均 200，主机基线未变。精确清理本轮独立库 6 个、正式库 3 个测试账号，`8199` 已停止。
- 清理后正式库保留 8 个账号、48 条私聊、3 个群和 17 条群消息，与此次更新前备份一致，包括用户在验收期间新增的消息。
